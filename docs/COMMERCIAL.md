这份文档说清楚三件事：什么规模不用找我、什么规模必须找我、找我之后会拿到什么。

---

## 一、你现在不用找我

同时满足下面两条，直接用，不用发邮件，也不用署名给我：

- 你的公司（含母公司、子公司、同一控制下的关联方）**员工加独立外包合计少于 100 人**；
- 上一个纳税年度**总收入低于 100 万美元**（按美国劳工统计局 CPI-U 通胀调整后的等值）。

个人用它做私活、接单、给客户交付，只要你自己不属于上面那个「大公司」，都算允许用途。

这不是我的额外恩典，是这份许可自带的条款。装了就生效。

## 二、这几种情况也不用找我

不管公司多大，下面这些都不需要商业授权：

- 评估、试用、做技术选型对比，不进入生产；
- 在自己的博客、文章、课程里演示它；
- 读源码、改源码、把自己的改动发 PR 或另开分支（遵守 LICENSE 里 Distribution 和 Notices 那两节即可）；
- 学术研究、非营利的内部试验。

## 三、超过门槛，必须找我

公司规模越过上面两条之一，还想继续用，就需要一份书面授权。授权按年签，不按下载量算。

**价位**（人民币，含税，一年）：

| 档次 | 适用 | 年费 |
|---|---|---|
| 小团队 | 100–500 人，或年收入 100 万–500 万美元 | 2,000 |
| 中型 | 500–2000 人，或年收入 500 万–5000 万美元 | 8,000 |
| 大型 | 2000 人以上，或年收入 5000 万美元以上 | 20,000 起 |

价格是按年一口价，不按人头、不按项目数加钱。多买多年按年数直接乘，不打折也不涨价。

三个档次都包含：

- 在授权范围内的公司内部部署与生产使用，不限席位数、不限项目数；
- 授权期内发布的版本，永久可用；不续费不影响已发布版本的继续使用；
- 邮件支持，工作日 48 小时内回复；
- 一份可签署的中文授权书，含授权范围、期限、费用、双方责任与争议解决条款，能直接进采购流程。

超出范围的需求单独谈：白标转售、集成进对外商业产品、代运维托管、定制开发。

## 四、怎么找我

一封邮件，写清这四项就够，不用写长：

1. 公司名称与大致规模（人数、上一财年收入区间）；
2. 打算怎么用（内部流程 / 交付客户项目 / 集成进产品）；
3. 预计多少人在用；
4. 想要哪个档次，或者直接说「按你们的标准报」。

**联系方式**：2479465655@qq.com

回复时限：工作日 48 小时内给第一封回信，含报价和授权书草稿。超过三天没收到，再发一封，可能进了垃圾箱。

## 五、不找我而继续用会怎样

LICENSE 的 Violations 一节写的是：第一次收到书面告知后 32 天内整改到位，授权仍然继续；逾期未整改，授权立即终止。

也就是说这份许可给了补救期，不是一发现就断。但授权终止之后继续使用，就是侵权，走的是著作权法那套。

我不打算满世界查。这套条款的作用是让愿意守规矩的公司有个明确的路径可以走，不是用来钓鱼的。

## 六、一点实话

这插件是明文 JavaScript 发布的，任何人 `npm i` 就拿到全部源码。条款拦不住谁，也没打算拦。

写在这里只是为了让要走采购流程的公司知道：这事有正规路径、有价格、有人回信。你按规矩来，我按规矩给授权书；你规模不到，连招呼都不用打。
